# Online Bookstore SQL Database

A relational SQL project simulating an online bookstore backend. Demonstrates table design, relationships, and advanced SQL queries.

## Features

- Fully normalized schema (3NF)
- JOINs, subqueries, aggregation, views
- Real-world concepts: customers, orders, books, reviews
- Great for data or backend developer roles

## Tables

- Authors
- Books
- Customers
- Orders + OrderDetails (for many-to-many)
- Reviews

## Files

- `schema.sql` – Table creation
- `insert-data.sql` – Sample data
- `queries.sql` – Queries using joins, grouping, filters
- `views.sql` – Sample view for top-rated books
